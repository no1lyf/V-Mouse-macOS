# Security Policy

## Reporting a Vulnerability

V-Mouse鼠标映射 requires sensitive system permissions (Accessibility and Input Monitoring), so security is taken seriously.

If you discover a security vulnerability, please report it by:

1. **Open a private security advisory in this repository** (preferred).
2. If private reporting is not enabled, open a minimal issue that does not include exploit details and ask the maintainer for a private contact channel.

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

## What to expect

- Maintainers will confirm receipt when the report is reviewed.
- Details should remain private until a fix is available.
- Reporters may request attribution or anonymity.

## Supported versions

Only the latest release receives security updates. Please update to the newest version before reporting issues.

## Scope

Security issues include:
- Unauthorized access or privilege escalation
- Data exposure or keystroke logging beyond intended functionality
- Bypass of macOS security features
- Code injection vulnerabilities
