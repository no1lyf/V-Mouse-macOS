## 这是什么

V-Mouse鼠标映射是一款面向 macOS 的鼠标按键二次映射工具。它可以读取鼠标当前输出的板载键值，在不改写鼠标板载内存的前提下，将这些键值再次映射为键盘按键、组合快捷键、鼠标操作、系统功能、打开应用或文件、执行命令、输入文本、宏、切换配置，以及 Mos 风格的滚轮控制。

鼠标先按照自身板载配置向 Mac 发送按键值，V-Mouse鼠标映射读取后，再决定让原输入直接通过、完全屏蔽，或执行用户设置的 Mac 动作。这个过程属于软件层面的二次映射，不会修改鼠标固件或板载配置。

所有内容都**只保存在你的 Mac 上**。程序以只读、非独占方式打开鼠标：从不改写板载按键、宏、灯光或 DPI，也不会把设备从系统夺走。

它围绕 **Razer Naga V2 HyperSpeed** 打造，同时也支持你手动选择的普通标准 HID 鼠标和键盘。

## 主要特性

- **板载键值录入**——对每个输入，在 20 秒倒计时内连按三次；程序记录 HID 信号、对应的系统事件和两者时间差。只读：只识别你的信号，不修改鼠标。
- **精确拦截**——运行时每次 HID 按下/释放只生成一个短时、一次性令牌。只有事件类型、按下/释放阶段、键码**和**校准时间戳全部匹配时，Event Tap 才拦截，因此物理键盘绝不会被误认成鼠标。每个输入都有独立的**「拦截板载键值」**开关；关闭时原信号直接通过。
- **丰富的动作类型**——按键序列、macOS 快捷键（按 Mos 分组：功能键、窗口与应用、文档编辑、访达、系统、截图、导航、修饰键）、打开应用/文件/文件夹/网址、shell 命令、文本片段、宏、切换配置、鼠标点击，以及按住型滚轮控制。
- **滚轮增强**（移植自 [Mos](https://github.com/Caldis/Mos)）——平滑滚动，垂直/水平独立反向，模拟触控板，步长/速度/持续时间/死区可调。加速、纵向转横向、临时禁用平滑三个按住型控制。触控板手势被排除、保持原样。
- **内置触控板联动**——可在主页面开启“连接外接鼠标时停用内置触控板”。应用仅在自身运行且检测到外接鼠标时请求系统停用，关闭选项、拔出外接鼠标或退出应用时恢复。
- **多设备与身份规则**——默认以 VID/PID 作为设备族身份；可按设备族启用增强识别，所有已启用条件必须同时匹配。每台设备保存自己的板载键值表，并可共用同一配置文件。
- **配置挂载**——设备最多启用一个配置，也可以不启用配置；最后一个配置仍可“从此设备移除”。零配置设备不执行 Mac 动作、不进行普通拦截，板载输入默认直通；只有用户明确开启的设备级“⌘ ⇄ Control”互换仍会生效。配置文件保留在“未挂载配置”中。
- **个性化**——默认分组和自定义分组均可改名、排序并在清空后删除；可在任意分组读取新输入。配置文件可新建、复制、共用、导入和导出。
- **原生且本地化**——纯 AppKit，跟随 macOS 浅色/深色外观，三种主题（毛玻璃 / 黑夜 / 原始黑色）。五种应用内语言：简体中文、English、日本語、한국어、Deutsch。可选开机自动启动。

## 系统要求与权限

- **macOS 13（Ventura）或更高版本。**
- **输入监控**——读取鼠标的原始 HID 报告。
- **辅助功能**——建立拦截用 Event Tap 并发送你配置的动作。
- **蓝牙**（可选）——仅用于读取蓝牙鼠标的电量。

程序不创建虚拟 HID 设备，不独占鼠标，也不需要 Apple 的特殊 HID entitlement。请在**系统设置 → 隐私与安全性**中授予输入监控和辅助功能权限。

## 支持的设备

- **Razer Naga V2 HyperSpeed**——通过蓝牙和 USB 2.4GHz HyperSpeed 接收器，使用专用、字节级精确的报告解码器。
- **标准 HID 鼠标和键盘**——任何你手动选择的设备，支持键盘、Consumer、System Control 和鼠标第 3 键及以上。厂商私有协议和未知设备会**标明无法驱动的原因**，而不是无声地猜测解析。

每台设备初始提供**侧键 1–12、DPI+、DPI−、滚轮左键、滚轮右键**，还可建立自定义分组并继续读取新输入。新输入按“自定义键 1、2……”排序命名，之后可改名或移动到其他分组。DPI± 只有在你先于鼠标板载（Windows）配置中把它从 Razer 私有 DPI 功能改成普通键值后才可录入；程序自身从不写入。

## 构建与自检

```bash
bash Scripts/build_app.sh
```

脚本会生成 Release 程序，运行内置自检（报告解码、HID 键码、一次性令牌路由、多设备隔离、五语言完整性），创建 ad-hoc 签名的 `V-Mouse鼠标映射-v0.7.4.app` 并打包为 `V-Mouse鼠标映射-v0.7.4.dmg`。文件名只包含版本号，不再附加日期。

单独运行自检：

```bash
./V-Mouse鼠标映射-v0.7.4.app/Contents/MacOS/NagaController --self-test-hid-codec
```

设计约束、判源模型和稳定性保证详见 [V-Mouse鼠标映射_Architecture.md](V-Mouse鼠标映射_Architecture.md)。

## 如何保证安全

- 只读、非独占 HID 访问——即使关闭映射，鼠标也照常工作。
- 从不写入板载按键、宏、灯光或 DPI。
- 拦截逐事件靠 HID 时间戳证明，绝不凭裸键码，从而保护物理键盘。
- 设备断开、Event Tap 失效、配置变化、宏取消或退出时，统一释放所有合成输入；Event Tap 被停用后自动恢复。
- 配置只存在于你的 Mac 上。
